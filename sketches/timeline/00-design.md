# tlt-timeline 设计（V3 · 尺度自适应 + 下钻 + 就地编辑）

原型：`03-drill.html`（当前版，可交互）｜`01-design.html` / `02-interactive.html` 为历史版本

打开方式：`python3 -m http.server 8801`，然后 `http://127.0.0.1:8801/03-drill.html`
（带参数可直接进某个尺度：`?auto=decade` / `?auto=year` / `?side=0` 收起侧栏）

## 1. 数据模型：块自己就是数据

```tlt-timeline
date: auto
view: flow
```

# 时间段（有起止 → 画成条）
- 11:30–12:15 湖南算法核减项与项目组讨论 [proj:: 交通核心算法研发]
- 13:30–15:10 部门里程碑 & 任务梳理 [proj:: mvlab 运营管理]

# 时间点（单一时刻 → 画成点，永远保留）
- 10:12 一车一档 V2.0 需求评审 [proj:: 交通核心算法研发]
- 13:00 taisl_okc 图谱交付 [proj:: omniwise]

正文写法（支持 Markdown，会渲染）：

```
- 11:30–12:15 湖南算法核减项与项目组讨论
  ｜一句话：把核减逻辑改成规则引擎，误差 8% → 2%
  ｜#### 结论
  ｜- 规则引擎 + 词表双轨
  ｜> 会上定的口径：必须能回指规则条目
  ｜```ts
  ｜const drop = score < 0.55;
  ｜```
```

| 写法 | 含义 | 画法 |
| --- | --- | --- |
| `HH:MM–HH:MM 标题` | 时间段（日尺度） | 条，长度=时长 |
| `2026-04-08 → 2026-06-30 标题` | 时间段（跨日/跨月/跨年） | 条，按月份定位 |
| `HH:MM 标题` / `2021-11-05 标题` | 时间点 | 圆点，不进时长统计 |
| `[proj:: X]` | 颜色与泳道归属 | 取项目色 |

**写回**：`ctx.getSectionInfo(el)` 取块的行号 → 只替换块体那几行 → `vault.process()`。
块内还有 `[id::]` 隐式锚点（写回时自动补），便于外部文件引用同一条。

## 2. 尺度自适应（回答"多年历史 / 小说时间线"）

同一份数据，四个尺度，**自动选**：

| 尺度 | 一行 = | 横轴 = | 适用 |
| --- | --- | --- | --- |
| **十年** | 一年（空的年份也保留，行高压扁） | 1–12 月 | 十年日记、跨多年的项目史 |
| **年** | 一个月 | 1–31 日 | 一本书、一年的项目 |
| **月** | 一天 | 小时 | 排期 |
| **日** | 一小时段 | 6–24 时 | 回顾今天（航道/泳道/表盘/周脉冲） |

- 打开时按数据跨度自动定尺度：跨度 > 3 年 → 十年；> 100 天 → 年；> 3 天 → 月；否则日。
- 缩放是一条连续的路径：**日 ↔ 月 ↔ 年 ↔ 十年**（`⌘+`/`⌘-`、滚轮、面包屑、双击都可）。
- 小说 / 虚构时间线：允许 `date` 写 `2016-03-08`，也允许写 `纪年:3-04-11`（自定义历法），按字符串排序；不支持自定义历法的场景就用真实日期占位。

## 3. 下钻交互（Apple 式：由大到小、由浅及深）

**一条规则**：点任何东西 = 放大一层 + 弹出它的内容。

```
十年 ─点一条经历/一个点─▶ 那年（浮层留在原地，时间轴平滑放大）
     ─再点─▶ 那月 ─再点─▶ 那天（航道）
```

- 面包屑 `全部 › 2026 年 › 11 月 › 2026-11-02` 常驻，任何一级可点回去。
- 浮层（点击后弹的内容卡）：标题 + 时刻/时长 + **Markdown 正文渲染** + 三个动作（编辑 / 打开笔记 / 在一年里的位置）。
- 浮层出现时，图上对应的条/点高亮，背景不变暗——**不是弹窗，是"拉近一层"**。
- 键盘：`⌘+ / ⌘-` 缩放，`←/→` 前后一天/一月/一年，`Esc` 关浮层。

## 4. 内容很多的条目（几百字 + Markdown）

- **主图只放"形状"**：条的长度 = 时长，点的位置 = 时刻；条内最多写 8–10 个字，超了就截断。
- **正文放浮层**：点击后在浮层里按 Markdown 渲染（标题、列表、代码块、引用、图片、双链都支持）。
- 浮层：宽 480px、高 76vh、**头尾固定、正文独立滚动**；正文里 `##` 折叠为小标题，长文可滚动不撑破。
- 条上还带 `≡` 标记（有正文）→ 提示"这条有内容"。空白条和带正文条一眼可分。
- 悬停只给一行摘要（时间 + 标题 + 项目），不抢注意力。

## 5. 完成时刻 / 时间点 —— 与时间段并列，不是开关

- 一个用户不该关心的差别：**点 = 时刻，条 = 区间**，两者是不同事实，都保留。
- 日尺度：时间点排在轴上方一条独立"时间点轨道"（圆点 + 时刻），时间段在下方按并发叠层。
- 时间点不参与"在轴时长"，但参与"时间点"计数与完成度统计。
- 时间点的标题在悬停/选中时显示；密集时自动分层（同一分钟多个点错开）。
- 之前那版把"完成时刻"做成开关是错的——现在两种情况并存，不需要用户切换。

## 6. 空档：不标注

去掉了"空 1.8h"这类标注。**没记录就是没画**，空白本身就说明问题。
若以后要看"空档分析"，单独放一个统计项（如"空档合计"），不在图上画。

## 7. 侧栏（可折叠）

- 右侧"这一天"面板默认展开，点 `✕` 收起，主图立刻占满宽度，左边缘留一个竖排「编辑」把手。
- 侧栏有两种状态：**列表态**（当天时间段 + 时间点）和**编辑态**（点某条后进入，含标题/时间/项目/正文，正文用 textarea + 实时预览）。
- 不需要编辑时它不挡事：收起后所有编辑仍可从图上点击进入。

## 8. 实现要点（Obsidian 侧）

- `registerMarkdownCodeBlockProcessor("tlt-timeline")` + `MarkdownRenderChild`；`onunload` 清理监听、`ResizeObserver`、浮层。
- 行号定位 `getSectionInfo`；外部改动时以文件为准重新解析，不缓存 items。
- 写回 `vault.process(file, fn)` 只替换块体；不 `modify` 整篇。
- 拖拽用 `pointerdown/move/up`，但重绘会替换节点 → 监听挂 `window`，坐标用开始时的 `getBoundingClientRect()` 快照（**这次原型踩过的坑**）。
- 浮层：`position: fixed` + 内部滚动；`Esc` 关闭；打开时把焦点移进浮层。
- 只有"点/条"是可编辑对象；正文写回同一行下的缩进块。
- 实时预览里光标在块内时不渲染（Obsidian 默认），出块即渲染。

## 10. 还没定 / 下一轮要拍的

1. **自定义历法**（`纪年:3-04-11`）要不要 v1 就支持？还是先只支持真实日期。
2. **尺度切换动画**：原型是瞬时切；真实实现要做 300ms 的平滑过渡（条的起飞/落地），还是保持瞬时？
3. **周脉冲 / 表盘**在年尺度下的对应物（年脉冲？年轮？）要不要做。
4. **浮层的宽窄**：480px 够不够，长文要不要给"全屏阅读"。
5. **移动端**：拖拽与页面滚动手势的边界；侧栏在窄屏改为底部抽屉。
