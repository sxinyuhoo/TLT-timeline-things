# 数据格式

全部是普通 Markdown。插件只读 `TLT/` 下的这几处（路径可在设置里改），不做全库扫描。

```
TLT/
├─ tasks/<项目>.md      任务
├─ team/<姓名>.md       人员
├─ feeds/<源名>.md      消息源
├─ logs/<YYYY-MM>.md    记录（按月）
├─ ideas.md             随手记
└─ tags.md              标签库
```

## 任务 `TLT/tasks/<项目>.md`

一个项目一个文件，`##` 是里程碑，一行一条任务，两格缩进是子步骤。

```markdown
# 示例项目

## V0.7.4 月报

- [ ] 示例任务：报告定稿 🛫 2026-10-20 📅 2026-10-25 [wl:: 30] [pri:: 2] [owner:: [[我]]] [tags:: 周报] [st:: 09:00] [en:: 10:30]
  - [ ] 汇总场景数据
  - [ ] 对口径
- [x] 示例任务：周报 📅 2026-10-18
```

| 字段 | 含义 |
| --- | --- |
| `🛫 日期` | 开始 |
| `📅 日期` | 截止 |
| `[wl:: 30]` | 占比（%），必须配 `[pw:: w\|m\|q]` 周期，默认本月 |
| `[est:: 2]` | 人天（可选，和占比二选一） |
| `[pri:: 0-3]` | 优先级，0 低 / 3 紧急 |
| `[owner:: [[甲]], [[乙]]]` | 负责人，双链到 `team/` |
| `[tags:: 周报, 评测]` | 标签，逗号分隔 |
| `[st:: 09:00] [en:: 10:30]` | 排进时间轴的具体时段 |

勾选框直接改写原行，不重写整个文件。

## 人员 `TLT/team/<姓名>.md`

```markdown
---
tlt: staff
role: 算法工程师
capacity: 80        # 产能（百分比）
days: 4             # 每周在岗天数
skills: [评测, 标注]
status: active
---
```

饱和度 = 该周期未完成任务的占比合计 ÷ 产能。

## 消息源 `TLT/feeds/<源名>.md`

一行一条消息，`>` 缩进是正文。

```markdown
---
title: 部门通知
owner: 示例同事
mine: true          # 我发布的
personal: false     # 个人草稿源标 true
cadence: 每周 2-3 条
remote: https://example.com/feed?id=dept   # 订阅来的源，记原始地址
---

- 2026-10-22 周会改到周四 [kind:: ask] [place:: 三楼] [who:: [[示例同事]]] [why:: 避开例会] [tags:: 会议] [star:: true] [state:: live]
  > 时间改成 10:00。
```

| 字段 | 含义 |
| --- | --- |
| `[kind:: ask\|event\|risk\|note]` | 性质（可选，现阶段界面不再让填） |
| `[place:: 三楼]` | 地点 |
| `[who:: [[甲]], [[乙]]]` | 人物 |
| `[why:: …]` | 缘由 |
| `[tags:: a, b]` | 标签 |
| `[star:: true]` | 标重要 |
| `[state:: ended]` | 已结束（订阅方会看到划掉） |
| `[mid:: …]` | 订阅去重键，同步时写入 |

## 记录 `TLT/logs/<YYYY-MM>.md`

按月一个文件，`## 日期` 分节，时间块一行一条。

```markdown
## 2026-10-22

- 09:30–11:00 示例记录：核对口径 [proj:: 示例工具]
  > 对了三处口径。
- 11:00–11:40 需求对齐会 [proj:: 示例项目] [extra:: true]
```

`[extra:: true]` 表示计划外临时插入，日历里会单独统计。

## 随手记 `TLT/ideas.md`

```markdown
- 把常用脚本做成通用回归工具 [type:: 工具] [stage:: 待验证] [star:: 2] [at:: 2026-10-20] [tags:: 工具]
  > 现在每次迭代都要人工抽 100 份。
```

快速输入支持 `#标签 @阶段 正文`：`#论文 #回归 把常用脚本做成工具`。

## 标签库 `TLT/tags.md`

```markdown
# 标签

- 论文
- 专利
- 工具
```

界面里改名会同步改所有用到它的随手记；删除会从随手记里一并移除。
